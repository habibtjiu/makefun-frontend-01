A fast, dense board for make.fun bounties: the live board stays beside every bounty page, leaderboard and profile, reading only make.fun's public API. Vanilla JavaScript, no framework, ETag-revalidated reads, paged leaderboards.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
